📖 Read.me — System Architecture

1. Zero Login & Ephemeral Identity

No passwords or databases required. Each session generates a 24-digit numeric identity (`crypto.getRandomValues`). All ephemeral state self-destructs upon session termination.

2. Device Hardware Execution

Audio, video encoding, screen capture, and telemetry processing run locally on device CPU/GPU worker threads via Web Worker loops.

3. Strict 10-Minute Session Limit

Sessions strictly enforce a 10:00 (600s) maximum countdown timer to ensure fair peer turnover across the network.

4. Instant Background Termination

Leaving the active tab or backgrounding the browser triggers `visibilitychange` to immediately stop all media tracks, terminate Web Workers, and purge memory.

⚖️ Terms & Technical Limitations

Bank Payment Verification Notice

Peer Discovery Scope

Direct peer discovery across multiple open browser tabs uses `BroadcastChannel`. Single-tab execution falls back to curated telemetry peer nodes for evaluation.

No Server Storage Disclaimer

The platform operates without central data storage. Users must explicitly grant media permissions via browser prompts upon session launch.
